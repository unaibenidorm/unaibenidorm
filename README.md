### 🌊 [WaveSync](https://github.com/unaibenidorm/WaveSync)
> **Universal Audio Track Synchronizer for Video with Sub-Millisecond Precision**

![Python](https://img.shields.io/badge/Python_3.11+-3776AB?style=flat-square&logo=python&logoColor=white)
![GTK4](https://img.shields.io/badge/GTK_4-4A90D9?style=flat-square&logo=gnome&logoColor=white)
![Libadwaita](https://img.shields.io/badge/Libadwaita-2E3436?style=flat-square&logo=gnome&logoColor=white)
![GStreamer](https://img.shields.io/badge/GStreamer-FF4500?style=flat-square)
![FFmpeg](https://img.shields.io/badge/FFmpeg-007808?style=flat-square&logo=ffmpeg&logoColor=white)
![SciPy](https://img.shields.io/badge/SciPy_%2F_DSP-8CAAE6?style=flat-square&logo=scipy&logoColor=white)

A modern Linux desktop application and headless CLI that extracts audio tracks from secondary releases (in any language or dub) and **automatically synchronizes them with sub-millisecond precision** into high-quality master releases (**4K UHD Remux, HDR/Dolby Vision**) **without re-encoding video**.
- **100% Language-Independent Pipeline:** Combines rank-order normalized visual frame alignment with **GCC-PHAT** audio phase correlation and **RANSAC** tempo/cut modeling (`25 ↔ 23.976 ↔ 24 fps`).
- **Live A/B Comparator:** Powered by **GStreamer** with shared pipeline clocks for zero-latency switching between Master Audio A and Synchronized Dub B.
